## Ученическа олимпиада по програмиране 30 март 2025 г.
# Магически отвари

В магическа лаборатория има N бъчви с различни магически отвари, подредени в линия. Всяка бъчва съдържа цяло положително число литри магическа отвара.

Вашата цел е да изпиете максимално количество отвара, като спазвате следните правила:

- Не можете да пиете от две съседни бъчви.
- Можете да изберете произволни бъчви, стига да не са съседни.
- Не сте длъжни да пиете от първата или последната бъчва

Програмата трябва да обработи T тестови примера, като за всеки намери максималното количество отвара, което може да се изпие.

## Input Format

- Първият ред съдържа цяло число T (1 ≤ T ≤ 100) — броят на тестовите примери.
- Следват T тестови примера.

За всеки тестов пример:
- Първият ред съдържа цяло число N (1 ≤ N ≤ 100,000) — броят на бъчвите.
- Вторият ред съдържа N цели числа M[i] (1 ≤ M[i] ≤ 10⁹) — литрите магическа отвара във всяка бъчва.

## Constraints

- 1 ≤ T ≤ 100 
- 1 ≤ N ≤ 100,000 
- 1 ≤ M[i] ≤ 10⁹

## Output Format

Програмата трябва да изведе T реда, като за всеки тестови пример се извежда едно число — максималното количество отвара, което може да се изпие, без да се пие от две съседни бъчви.

## Sample Input 0

```
2
5
4 1 7 9 3
6
8 2 10 1 6 4
```

## Sample Output 0

```
14
24
```

## Explanation 0

Обяснение:
- Първи тест: Оптимален избор: бъчва 1, бъчва 3, бъчва 5 → 4 + 7 + 3 = 14
- Втори тест: Оптимален избор: бъчва 1, бъчва 3, бъчва 5 → 8 + 10 + 6 = 24

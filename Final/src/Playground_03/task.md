## Ученическа олимпиада по програмиране 30 март 2025 г.
# Площадка за игра

В един град децата обичат да се събират на голяма площадка за игра. Веднъж в годината, всички деца организират събитие, при което трябва да се подредят в кръг. Всяко дете е уникално и подредбата е важна, защото ще се снимат за спомен. Задачата ви е да изчислите по колко различни начина децата могат да се подредят.

## Input Format

На първия ред на стандартния вход се задава броят T, където 0 < T ≤ 20000.
Следват T теста. Всеки тест се състои от единствен ред, съдържащ едно цяло число N (1 ≤ N ≤ 1000), което представлява броя на децата.

## Constraints

- Брой тестови случаи (T): 0 < T ≤ 20 000
- Брой деца (N): 1 ≤ N≤ 1000

## Output Format

За всеки тест изведете броя на всички възможни подреждания на децата в кръг.

## Sample Input 0

```
2   
5   
6  
```

## Sample Output 0

```
24   
120
```
